# Vaibhav Tyagi — personal website

A static site (plain HTML/CSS/JS, no build step), so it hosts free on GitHub Pages.

Design: a "radar console" theme — dark by default (light mode via the button in the menu),
coloured with the NWS reflectivity (dBZ) scale. All radar/wind visuals are synthetic simulations.

```
index.html          Home: live radar scope (reflectivity/velocity, clutter filter), products, papers, bulletin
research.html       4 research areas, each with an interactive demo:
                      QC slider (raw vs filtered) · wind flow field · Z–R rain-rate · scatterometer rain flag
publications.html   Filterable, searchable list grouped by year, with "copy citation"
experience.html     Education & Experience: storm track with logos, campus photos, one filterable timeline
awards.html         Awards colour-coded by year (filterable), service, memberships
contact.html        "Station info" card with live local/UTC time, profile links

data.js      ALL the content: news, papers, jobs, awards, research areas, projects, links  ← edit this
viz.js       the radar / wind / rain simulations (no need to touch)
site.js      shared header (ticker + menu), footer, page logic (no need to touch)
styles.css   design (colours are at the top under :root)
assets/      put your portrait here as profile.jpg (shown in the Home "Research vision" section)
assets/edu/  institution logos + campus photos (from Wikimedia Commons; credits are shown on the
             Education & Experience page and listed in data.js → institutions; the IIT Palakkad logo
             is the official one from iitpkd.ac.in). Add a Delhi University photo here and set its
             path in data.js to show it.
```

The header and footer are generated by `site.js`, so a new menu link only needs adding
once — in the `PAGES` list at the top of `site.js`.

## Adding a new paper, award or news item
Open `data.js`, copy an existing entry, change the fields, save, and upload/commit.
Publications are sorted and grouped by year automatically; the counters update themselves.
Awards marked `featured: true` appear on the home page.

## Previewing on your computer
Opening `index.html` by double-clicking works for most things. For the full experience
(page transitions etc.), run a local server from this folder, e.g. `npx http-server` (needs Node.js),
then open http://localhost:8080.

## Publish free on GitHub Pages

### Option A — no command line (easiest)
1. Sign in at https://github.com and click **New repository**.
2. Name it exactly **`<your-username>.github.io`** (for example `vt-tyagi.github.io`). Make it **Public**.
3. On the new repo page click **uploading an existing file**, drag in all six `.html` files,
   `styles.css`, `site.js`, `viz.js`, `data.js`, `README.md` and the `assets` folder, then **Commit changes**.
4. Go to **Settings → Pages**. Under *Build and deployment* choose **Deploy from a branch**,
   branch **main**, folder **/ (root)**, then **Save**.
5. After ~1 minute your site is live at **`https://<your-username>.github.io`**.

To update later, open the file on GitHub, click the pencil icon, edit, and commit — the site
redeploys automatically.

### Option B — with git
```bash
cd vaibhav-website
git init
git add .
git commit -m "Initial site"
git branch -M main
git remote add origin https://github.com/<your-username>/<your-username>.github.io.git
git push -u origin main
```
Then do step 4 above.

### Optional: your own domain (~$10/year)
Buy a domain (e.g. `vaibhavtyagi.com`) from any registrar, then in **Settings → Pages → Custom domain**
enter it, and add the DNS records GitHub shows you. HTTPS is free. Hosting itself stays free.

## Pointing the old Wix site to the new one

A true automatic (301) redirect to an external site is **not** available on a free Wix site
(`*.wixsite.com`) — Wix's redirect tools only work on Premium sites with a connected domain.
Free options, best first:

1. **Replace the Wix homepage with a "moved" notice.** In the Wix editor, delete the page
   content and add a large heading and button:
   *"My website has moved → https://<your-username>.github.io"*. Publish.
   This always works. Do the same on the other pages, or delete them so visitors land on Home.

2. **Try an automatic redirect via Embed code** (may or may not work — Wix runs embeds in a
   sandboxed frame and can block it). In the editor: **Add → Embed Code → Embed HTML**, choose
   *Code*, paste:
   ```html
   <script>window.top.location.href = "https://<your-username>.github.io";</script>
   <p style="font-family:sans-serif">Moved to <a href="https://<your-username>.github.io" target="_top">https://<your-username>.github.io</a></p>
   ```
   Publish and test in a private window. If it doesn't jump automatically, the link still works.

3. **Update everywhere the old link appears** — this matters more than the redirect for people
   finding you: Google Scholar profile homepage, LinkedIn, ResearchGate, GitHub profile, email
   signature, and your CV (which currently lists the Wix URL).

4. Once the new site is indexed by Google (a few weeks), you can unpublish the Wix site.
